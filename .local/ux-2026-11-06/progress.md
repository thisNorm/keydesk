# UI·UX 진행 기록

- 사용자 요청: 일반 사용자 관점으로 기능·동작·배치를 판단해 실제 앱을 개선한다.
- 방향: 상단 메뉴, 전체 폭 목록, 행 아래 펼침. 기존 색 상태 띠·카드·사이드바·고정 오른쪽 상세는 채택하지 않는다.
- 기준 스냅샷: .local/ux-2026-11-06/before. 원래 미커밋 재구축 변경은 유지한다.
- 제품 데이터·백엔드·HTTP 형식·의존성·게시 설정은 변경하지 않는다.
- Task 1 폼, Task 2 설정은 파일 소유권을 나눠 진행하고 루트가 목록·공용 UI·CSS·통합 검증을 담당한다.
- 로컬 커밋이나 push 없이 리뷰 가능한 작업 트리와 사전 비교 자료를 남긴다.

- 사전 전체 검사91/91 통과. 보기 헬퍼6개 검사의 RED(새 기능 없음)→GREEN, 기존 헬퍼 포함19/19 통과.
- 실제 브라우저 RED: 이전 버전1을 본 뒤 이력을 닫아도 다음 조회가 이전 값으로 남는 문제 재현. 새 Secret에서 현재 버전 복귀 및 늦은 복사 결과 방어 구현 중.
- 사용자 추가 기준: 불필요한 hover 밑줄, 카드 외곽선, 그림자·이동 효과 제거. 선택은 글자 굵기·펼침 상태, 입력과 키보드 포커스만 기능상 경계를 유지.

- 폼7개 모델 회귀검사 + 헬퍼20/20 통과 보고 수신. 루트가 EntryEditor/ImportEntries/RotateCredential를 실제 Vault에 연결했다.
- 실제 보관함은 전체 폭 table+행 아래 aside로 변경했다. 필터별 대상 날짜, 검색·조건 초기화, 저장 후 해당 행 선택과 갱신 실패 재조회 버튼을 연결했다.
