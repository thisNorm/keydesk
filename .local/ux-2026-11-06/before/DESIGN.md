# Keydesk 화면 기준

Norm이 API 키의 사용처와 만료일을 확인하는 개인용 작업 도구다. 첫 화면은 보관함 목록이며 필요한 순간에 상세와 인증값을 확인한다.

큰 숫자 카드, 홍보 문구, 반복 안내 배너, 제공사별 장식 아이콘과 과도한 배지를 넣지 않는다. 열 정렬, 짧은 필터, 읽기 쉬운 한글과 명확한 선택 상태로 정보를 구분한다.

기본 화면은 차콜 표면과 낮은 채도의 녹색 강조색을 사용한다. 밝은 화면도 같은 구조를 유지한다. 외부 폰트 없이 운영체제의 한글 글꼴을 사용하며 키·주소·수치에만 고정폭 글꼴을 사용한다. 상태는 색과 함께 글자로 표시한다.

넓은 화면은 목록과 상세를 나란히 표시하고 좁은 화면은 상세 패널로 전환한다. 검색·만료·프로젝트 필터와 키 보기·복사는 키보드로도 사용할 수 있어야 한다. Windows는 Ctrl, macOS는 Command로 표시한다. 한글 조합 중 Enter와 Escape가 저장·닫기를 실행하지 않게 한다.

한국어 날짜와 한국 시간을 기본으로 표시한다. 날짜만 입력한 만료일과 정확한 시각이 있는 만료일을 구분한다. 요금제 메모, 실제 관측 사용량, 추정 비용과 원화 환산값을 혼동하게 표시하지 않는다.

목록에는 키 값을 포함하지 않는다. 명시적으로 조회한 키는 잠금·이탈·시간 경과 시 지우며 복사 권한이 없으면 직접 선택하는 경로를 제공한다. 삭제·복원·비밀값 내보내기는 영향을 설명하고 확인받는다.
