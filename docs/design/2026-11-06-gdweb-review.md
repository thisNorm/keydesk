# GDWEB 검토와 Keydesk 화면 제안

2026년 11월 6일, 한국 시간 기준. 새 환경에 적용된 인터넷 허용 정책에서 실제 접속해 확인했다. 이전 UI 초안의 재적용이나 환경 설정 변경·게시는 수행하지 않았다.

## 제안하는 한 가지 방향

**차콜색 탐색 영역과 밝은 목록, 읽기 쉬운 만료일을 중심으로 한 개인 보관함.**

왼쪽은 보관함·프로젝트·만료 알림과 프로젝트 필터를 두고, 아래쪽에 향후 서버 운영 메뉴를 둔다. 가운데에는 API 이름·용도·키 개수·사용 프로젝트·가장 빠른 만료일을 정렬한다. 오른쪽은 선택한 항목의 각 키와 메모를 읽는 영역이다.

사용처와 만료일을 확인하려는 목적을 우선한다. 기본 정렬은 만료가 가까운 순이며, 만료된 항목도 발견할 수 있도록 목록 위쪽에 둔다. 만료일까지 남은 일수는 제목과 비슷한 강도로 보여주고 정확한 날짜를 함께 표시한다. 다른 연도에 만료하는 항목은 연도도 표시한다. 색 외에 `7일 남음`, `2일 지남` 문구를 함께 쓴다.

여러 키는 탭에 숨기지 않고 운영용·개발용처럼 이름과 만료일을 각각 펼쳐 보여준다. 이 이름들은 예시다. 실제 데이터의 키 이름을 그대로 사용할 수 있어야 한다. `보기`와 `복사`는 각 키 바로 옆에 둔다. 상세 패널에 표시한 요금제·한도는 직접 기록한 메모이며 실제 호출량이나 과금 상한과 연결된 것으로 표시하지 않는다.

글자 크기는 한글 본문과 설명을 읽을 수 있게 조정한다. 밝은 화면에서는 옅은 회색 바탕과 차콜 메뉴로 영역을 나누고, 어두운 화면에서는 중성 회색의 밝기 차이로 목록·입력칸을 구분한다. 낮은 채도의 녹색은 선택 상태와 주요 동작에 사용한다. 큰 통계 카드, 홍보 배너, 제공사별 장식 이미지와 그라데이션은 넣지 않는다.

## 등록 화면과 작은 창

키 추가는 이름·인증값부터 등록할 수 있는 구조로 제안한다. 프로젝트·용도·발급일·만료일은 함께 입력할 수 있고, 제공사·주소·요금제·메모는 펼치는 영역에 둔다. 여러 키의 수정 화면과 정확한 만료 시각 입력은 실제 UI 적용 전에 더 구체화해야 한다.

날짜 입력의 표기는 운영체제의 영문 월·일 순서에 의존하지 않도록 한국식 연·월·일을 제안한다. 초안의 날짜 입력은 시각 배치를 확인하는 텍스트 필드이며 완성된 달력이나 입력 검증 기능이 아니다.

노트북의 세로 공간을 위해 목록 간격을 줄이는 동작을 넣었다. 좁은 화면에서는 프로젝트를 선택 상자로 전환하고, 목록 항목을 누르면 상세 패널을 연다. Windows의 Ctrl과 macOS의 Command를 구분해 검색 단축키를 표시한다. 한글 조합 중에는 단축키가 동작하지 않게 한다.
