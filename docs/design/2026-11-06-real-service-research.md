# 실제 작업 도구를 기준으로 다시 검토한 Keydesk UI

2026년 11월 6일, 한국 시간 기준. 앞선 A/B 및 GDWEB 반영 시안은 사용자 피드백으로 채택하지 않는다. 사용자는 특히 사이드 상태 띠, 색 구성, 카드 배치에서 전형적인 생성형 사이트의 인상이 남는다고 지적했다. 특정 작품을 사용자에게 고르게 하지 않고 실제 유사 도구까지 조사해 방향을 제안한다.

이 피드백은 기존 `DESIGN.md`의 차콜·녹색 및 목록·오른쪽 상세 배치보다 우선한다. 이 문서는 새 제안이며 제품에 적용됐거나 사용자가 승인한 디자인 기준은 아니다.

이들은 동일한 서비스를 제공하는 경쟁사 목록이 아니라 비밀번호 보관·API 작업·데이터 탐색을 수행하는 실제 도구의 사례다. 확인 범위는 공식 페이지와 공개된 작업 화면이며 앱을 설치해 로그인하거나 실제 데이터를 입력한 결과가 아니다.

추가로 Secrets의 공식 사이트와 공개 자산을 확인했으나 확보한 이미지가 기능 소개용 그래픽이어서 작업 화면 근거에서는 제외했다. EnvKey는 접속이 403으로 거부되어 검토 완료로 기록하지 않는다.

## 새로 제안하는 구조

상단에는 제품 메뉴와 설정·잠금을 두고, 프로젝트는 목록 위의 선택 상자로 둔다. 목록은 화면 전체 폭을 사용한다. 바탕은 흰색, 글자와 구분선은 검정·회색이며 만료된 날짜에만 붉은색을 사용한다. 선택은 항목 이름의 밑줄과 펼쳐진 정보로 드러난다.

### 1. 행 아래에서 펼치기 — 우선 추천

API 이름이나 `+`를 누르면 그 행 바로 아래에 키 이름·인증값·만료일·보기·복사가 나온다. 항목과 인증값이 같은 위치에 있고, 사용하지 않는 상세 영역이 목록 폭을 계속 차지하지 않는다. 펼친 동안 아래쪽 행이 밀리는 것이 대가다.

[데스크톱 화면](previews/ledger-inline-desktop.png)

### 2. 목록 아래에서 보기

선택한 항목의 상세를 전체 목록 아래에서 보여준다. 목록의 위치를 유지하면서 여러 항목을 바꿔 볼 때 유리하다. 낮은 창에서는 상세를 확인하기 위해 아래로 이동해야 한다. 실제 제품에 채택할 경우 영역의 높이 조절과 키보드 이동을 검토해야 한다.

[데스크톱 화면](previews/ledger-bottom-desktop.png)

두 구조를 [같은 HTML](keydesk-ledger-concepts-2026-11-06.html)에서 전환해 비교할 수 있다. 검색·프로젝트·만료 필터·키 보기와 숨김을 확인할 수 있으며 실제 값을 저장하거나 복사하지 않는다. 나머지 메뉴는 예정된 이동을 설명하는 시안이다.

## 운영체제와 확인 범위

macOS와 Windows의 창 장식을 웹 페이지에 흉내 내지 않는다. 각 운영체제의 한글 글꼴을 사용하고 검색 단축키는 Ctrl/Command로 구분한다. 만료일이 등록되지 않은 항목은 `미등록`으로 표시한다.

Linux Chromium에서 두 구조, 검색·필터, 값 숨김, 1440·1280·760·600·390px의 가로 넘침을 확인했으며 브라우저 예외는 없었다. Windows·macOS에서 앱을 실행한 결과는 아니다. 새 후보는 색만 바꾼 이전 레이아웃이 아니라 항목과 상세를 연결하는 구조부터 비교하는 초안이다.

기존 제품 코드·사용자 데이터·환경 설정은 변경하지 않았고 게시하지 않았다. 외부 작품의 이미지·아이콘·글꼴·코드는 Keydesk 제품 자산으로 포함하지 않았다.
